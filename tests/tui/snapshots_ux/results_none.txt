Taking it to your real app:
  • Create a new workflow for your real app; don't edit playground.
  • Rename the methods to names for your real action and success, in the form
    <area>.<action> and <area>.<success>. Names starting with playground. are
    reserved for the tutorial, so keep them out of your real app.
  • Build the client with Client(api_key=os.environ["SIGNALGATE_API_KEY"]),
    with no playground transport.
  • Set uvicorn's forwarded_allow_ips (or your framework's proxy setting) to your
    proxy's address.

  - ev = sg_event(request, body.user, body.signalgate_log, "playground.action")
  + ev = sg_event(request, body.user, body.signalgate_log, "<area>.<action>")
  - ev = sg_event(request, body.user, body.signalgate, "playground.success")
  + ev = sg_event(request, body.user, body.signalgate, "<area>.<success>")
Next:
  1. In your app's repo, run the Claude Code plugin: /plugin marketplace add
     SignalGate/signalgate-claude-plugin, /plugin install signalgate@signalgate,
     then /signalgate:integrate.
  2. Docs: https://signalgate.ai/docs/backend
  3. Book a 30-minute call: https://signalgate.ai/about/contact
  4. The Quick Start steps you just completed count for this workspace. Your real
     app's events will show up under your own method names.
