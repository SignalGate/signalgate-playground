I started a small sample app on your laptop. It's what the simulated visitors will call.
Here's what will happen:

1. I'll send 10,000 visitors to a small app on your laptop. The visitors are real
   requests to the sample app I just started on your laptop. Each one triggers a
   protected action: the kind of action attackers abuse. Most of them are an
   attack: they trigger the action and never finish. You'll see how many actions
   turn into a real success. No SignalGate yet, no account needed.
2. You'll add two log() calls. Then I'll send a couple of thousand visitors through
   your code so SignalGate can learn what normal traffic looks like here.
3. You'll create a workflow in the dashboard and run a dry run: a one-time
   prediction of what blocking would change. A workflow needs enough events first:
   at least 1,000 actions is recommended, and we'll send more than that.
4. Once the workflow is live, you'll add one check() call before the action.
   Only then does SignalGate start deciding.
5. I'll run the traffic again and show you the before and after.

In a real app, SignalGate's browser script creates a sealed, single-use envelope for
every request, and your frontend sends it to your backend. Here I play the frontend:
I ask SignalGate for envelopes and attach them the way your frontend would. I can't
open them either. Only SignalGate can.

To connect, I need your SignalGate API key in app/.env.

New to SignalGate?
  1. Sign up at https://signalgate.ai/signup?utm_source=playground&utm_medium=cli&utm_campaign=0.0.1
  2. Verify your email.
  3. Open API access and create an API key and a public key.
  4. Paste the API key into app/.env.

Already have a workspace?
  Create a separate API key named playground in API access, and revoke it when
  you're done. Or use the key you already have.
  Never revoke a key your live app uses. If you don't have your key, ask your
  workspace owner, or use a separate workspace with another email.
  If you're a member (read-only), you won't be able to create the workflow in
  chapter 4.

Put your API key in app/.env after SIGNALGATE_API_KEY= and save it. Press Enter when it's saved.
